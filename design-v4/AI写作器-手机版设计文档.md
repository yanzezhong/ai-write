# AI 写作器 · 手机版设计文档（PRD 增补）

**文档版本**：V1.0（Mobile 增补）
**日期**：2026-10-18
**关联文档**：AI写作器·需求设计文档 V1（2026-10-06）/ 一键仿写功能 PRD V2 修订版（2026-10-09）

## 一、定位与范围

手机版是桌面版的**轻量延伸**，不是全量移植。只保留三个高频、低操作负担的场景：

| 功能 | 手机端定位 | 对应桌面版功能 |
|---|---|---|
| **一键仿写** | 完整保留，流程适配触屏 | V2 一键仿写全流程 |
| **基础编辑** | 只保留所见即所得单模式 + 基础格式 | Markdown 编辑器（砍掉源码模式） |
| **项目查看** | 项目列表、文档树、只读预览、大纲/人物浏览 | 项目管理 + 侧边栏应用 |

**明确不做**（手机端）：源码编辑模式、内嵌浏览器、多栏布局、人物库字段编辑（只读）、大纲拖拽排序（只读树）。

## 二、可行性结论

**结论：可行。** 功能取舍合理，架构上无需推翻现有设计，但有一处必须调整：

### 2.1 唯一硬障碍：文件存储

桌面版的根基是 File System Access API（项目 = 本地文件夹），**手机浏览器不支持**（Android Chrome 无 `showDirectoryPicker`，iOS Safari 整体不支持该 API）。

**解决方案：复用 FS Adapter 抽象层，新增 `MobileFSAdapter`**

```
FSAdapter（既有接口，业务层零改动）
├── WebFSAdapter      ← 桌面端：File System Access API（既有）
├── MobileFSAdapter   ← 手机端新增：OPFS（浏览器私有文件系统）
└── WebDAVFSAdapter   ← 预留：云端同步（后续路线）
```

- **OPFS（Origin Private File System）**：Android Chrome 86+ / iOS Safari 17+ 均支持，项目在浏览器内以"虚拟文件夹"形式存在，目录结构与桌面版完全一致（project.json / chapters/ / notes/ …）
- **导入/导出**：支持将项目导出为 zip、从 zip 导入——这是与桌面端交换数据的第一版方式
- **预留 WebDAV**：后续接入坚果云等 WebDAV 服务后，手机与电脑可共用一份数据

### 2.2 形态选择：响应式 H5

- 同一套 Vue 3 代码，通过断点（<768px）切换移动端布局，维护成本最低
- 后续可叠加 PWA 能力（添加到主屏幕、离线可用），形态接近 App，无需原生开发
- AI 模块、编辑器内核、FS Adapter、插件注册表全部复用，**移动端工作量 ≈ 布局组件 + 存储适配层**

### 2.3 风险与对策

| 风险 | 对策 |
|---|---|
| OPFS 数据被浏览器清理（长期未使用/存储压力大时） | 首页常驻「导出备份」入口；编辑时提示上次备份时间 |
| 手机端 AI 请求耗时长、易被打断 | 生成中支持后台继续 + 完成通知；断网自动保存已生成内容（沿用桌面版策略） |
| 小屏上长流程（仿写四步解析）迷失感 | 顶部固定步骤条 + 每步可回退，进度自动保存 |

## 三、信息架构与导航

### 3.1 页面层级

```
首页（项目列表）
 ├── 项目空间
 │    ├── 文档列表（默认页，含大纲/人物库入口）
 │    ├── 编辑器（点文档进入，全屏）
 │    └── 大纲 / 人物库（只读浏览页）
 └── 一键仿写（全屏流程）
      ├── 例文选择（底部弹层）
      ├── AI 分步解析（步骤 1-4，单栏堆叠）
      ├── 骨架编辑（Tab 切换四维度）
      └── 生成 → 完成 → 自动进入编辑器
```

### 3.2 导航规则

- **无底部 Tab**：手机版是"单任务流"应用，用系统级返回（左上返回键 + 手势）即可，不做常驻 Tab 栏，把屏幕高度全部留给内容
- **侧边栏应用 → 抽屉**：桌面版左右侧边栏的应用，在移动端统一收进编辑器右上角「☰」拉起的**底部抽屉**，以选项卡切换（文档 / 大纲 / 人物 / AI 聊天）
- **单例原则保留**：每种应用全局单例，与桌面版一致

## 四、功能设计

### 4.1 项目查看

**首页·项目列表**
- 项目卡片：项目名、文档数、总字数、最近编辑时间
- 长按卡片：重命名 / 导出 zip / 删除（二次确认）
- 顶部操作：「+ 新建项目」「导入项目（zip）」
- 底部常驻主按钮：「一键仿写」（与桌面版首页入口对齐）

**项目空间·文档列表**
- 顶部：项目名 + 总字数
- 分组列表：剧情大纲（outline.md）/ 正文（chapters/）/ 笔记（notes/）/ 资料库（library/）
- 点击文档 → 进入编辑器；左滑文档 → 重命名 / 删除
- 大纲与人物库为**只读浏览**：树状展开、人物卡片滑动浏览，不提供编辑（编辑回桌面端）

### 4.2 基础编辑

- **单模式**：仅所见即所得（类 Typora），不提供源码模式切换
- **顶部栏**：返回 / 当前文档名（点击可切换文档，拉起文档抽屉）/ 字数 / 「☰」应用抽屉
- **底部格式条**（键盘上方常驻）：加粗、斜体、标题层级、引用、列表、分割线——七个高频操作，无二级菜单
- **编辑即保存**：防抖自动写入 OPFS，与桌面版同一套保存逻辑
- **键盘适配**：格式条随键盘升降；iOS 安全区适配

### 4.3 选中文字 AI 操作（触屏版）

桌面版是"右键唤起"，手机端改为：

1. **长按选中文字** → 系统选区上方出现**浮动工具条**：`仿写 | 续写 | 润色 | 扩写 | 缩写 | ⋯更多（翻译/自定义指令）`
2. 点击动作 → **半屏 Sheet** 从底部升起：
   - 上半部：选中文本摘要 + 动作说明
   - 中部：AI 流式输出结果（Markdown 渲染）
   - 底部：追问输入框 + 「停止 / 重新生成」
3. 结果落回（每次由用户选择，与桌面版一致）：**替换原文 / 插入到原文之后 / 仅复制**
4. Sheet 可上拉至全屏（长结果场景），下滑关闭（结果未落回时二次确认）

### 4.4 一键仿写（移动端流程适配）

流程与桌面版完全一致：**例文选择 → AI 分步解析 → 骨架编辑 → 生成**，仅做布局适配。

**（1）例文选择**：底部弹层（非居中弹窗），两个选项卡「从资料库选择 / 粘贴例文」；粘贴框高度随键盘自适应

**（2）AI 分步解析**：桌面版"左对话 + 右结果"双栏 → 移动端**单栏堆叠**：
- 顶部固定：步骤条（世界观 → 人物 → 文风 → 大纲），当前步骤高亮
- 中部：当前步骤解析结果（条目卡片 / 人物卡片 / 大纲树）
- 底部：AI 对话条（输入修改意见），点击可展开为半屏对话历史
- 每步操作与桌面版一致：确认 / 提出修改 / 重新解析 / 上一步

**（3）骨架编辑**：桌面版"左导航 + 右内容" → 移动端**顶部 Tab**（世界观 / 人物库 / 文风样例 / 大纲）：
- 条目卡片全宽，编辑交互不变（input 常时可编辑）
- **锁定按钮 🔒 放大至 44×44pt** 触控热区，置灰 disabled 样式不变
- 「✨ AI 修改全部」「✨ AI 重新生成大纲」弹窗改为**全屏对话框**（小屏弹窗输入体验差）
- 底部固定栏保留：锁定计数 + 「生成文章」主按钮

**（4）生成阶段**：
- 模式选择（一次性 / 逐段）改为底部弹层两卡片纵向排列
- **逐段生成**移动端简化为单栏：顶部大纲进度条 → 中部当前段编辑器 → 底部 AI 面板（可展开）
- 生成中页面：进度条 + 当前章节提示，**支持切后台继续生成**
- 完成态：全屏完成页（非弹窗），展示统计（章节数/场景数/字数），主按钮「进入编辑器」

## 五、交互与视觉规范

### 5.1 触屏规范
- 所有可点目标 ≥ 44×44pt；列表项高度 ≥ 56pt
- 浮动工具条、Sheet、抽屉均支持手势关闭（下滑 / 侧滑返回）
- 长按 = 上下文操作（项目卡片、文档项）；左滑 = 快捷操作（文档列表）

### 5.2 视觉
- 完全复用 V2 色板与字体：主色暖赭石 `#B85C38`、背景暖米 `#F5F0E8`、文字深褐 `#3D3229`、衬线标题（思源宋体）+ 无衬线正文（思源黑体）
- 锁定态、AI 按钮可用/不可用态、进度条样式与桌面版一致
- 深色模式：本版本不做，预留 CSS 变量方案

## 六、数据与存储

| 内容 | 位置（手机端） | 说明 |
|---|---|---|
| 项目文件 | OPFS 虚拟文件夹 | 目录结构与桌面版完全一致 |
| AI 供应商配置 | localStorage | 与桌面版共用同一套设置页（移动端适配布局） |
| 最近项目列表 | localStorage | 记录 OPFS 内的项目路径 |
| AI 会话记录 | IndexedDB | 与桌面版一致 |
| 项目导入/导出 | zip 文件 | 导出 = OPFS 打包下载；导入 = 解压进 OPFS |

## 七、非目标（手机版明确不做）

- 源码编辑模式
- 内嵌浏览器应用
- 人物库/大纲的编辑（只读）
- 多文档选项卡、多栏布局（沿用桌面版决策并加码）
- 账号、云同步（预留 WebDAV 接口）
- 深色模式、平板横屏适配（后续迭代）
